## 목적

개발 실무에서 얻은 경험을 기록하고, 나중에 다시 참고할 수 있는 기술 지식 베이스를 만드는 것이 목표입니다.

## 다룰 콘텐츠

1. 백엔드/인프라 트러블슈팅 기록
2. 아키텍처/설계 개념 정리
3. 개발 생산성 도구와 환경 설정 노하우
4. 필요 시 게임/IT 관련 정보 스크랩

## 운영 원칙

1. 재현 가능한 절차 중심으로 작성
2. 설정값은 실제 동작 기준으로 검증 후 게시
3. 짧아도 결론과 체크리스트를 포함
4. 오래된 글은 분기별로 업데이트

## 작성 템플릿

1. 문제 상황
2. 원인 분석
3. 해결 절차
4. 재발 방지 체크리스트

## 정리

목표는 "읽고 바로 적용 가능한 글"을 꾸준히 쌓는 것입니다. 단편 메모보다 재사용 가능한 문서 형태로 관리합니다.
